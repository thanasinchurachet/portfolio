about me

นักพัฒนาหน้าใหม่

มีประสบการณ์พัฒนา Web Application ตั้งแต่ออกแบบฐานข้อมูล เขียน Backend / Frontend ไปจนถึงเชื่อมต่อ API และเทคโนโลยี AI ชอบทำเว็บที่ใช้งานง่าย สวย และมีชีวิตชีวา
